### TEMPLATE: exactly_one_true (AUTHORITATIVE)

You must implement the Designer plan using an **exclusive truth** structure.

#### Required stem structure
- Present **3–5 statements** (often conditionals) labelled clearly.
- Explicitly state:
  - “Exactly one of the following statements is true.”
- Ask which statement is true (or which option identifies the true statement).

#### Option form
- Options A–E (or A–F) correspond directly to “Statement 1”, “Statement 2”, etc.
- Exactly one correct.

#### Distractor requirements
Wrong options must reflect plausible reasoning slips:
- treating “at least one” as “exactly one”
- failing to check consistency between statements
- confusing implication direction
- missing a boundary case that flips truth status

#### Constraint
Keep it solvable without brute-force case explosion:
- 3 statements is safest; 4–5 only if cleanly constrained by the schema.
