### TEMPLATE: necessary_sufficient_conditions (AUTHORITATIVE)

You must implement the Designer plan using **conditions I/II/III** about a property and ask about necessity/sufficiency.

#### Required stem structure
- Introduce a target property P (e.g. “the equation has exactly one solution”, “the function is increasing”, “a statement is true”).
- Present **3 conditions** labelled **I, II, III**.
- Ask one of:
  - “Which condition(s) is/are sufficient for P?”
  - “Which condition(s) is/are necessary for P?”
  - “Which condition(s) is/are necessary and sufficient for P?”
  - “Which condition(s) guarantee(s) P?”
- Use “necessary/sufficient” language explicitly (Paper 2 style).

#### Option form (recommended)
- Use the same combination format as statement-combo questions:
  - I only / II only / III only / I&II / I&III / II&III / all / none
- 6–8 options depending on plausibility.

#### Distractor requirements
Wrong paths must reflect typical Paper 2 confusions:
- mixing up necessary vs sufficient
- assuming “if P then I” implies “if I then P”
- assuming “I only if P” means “I implies P”
- forgetting an edge case that breaks sufficiency
- using an example to claim necessity

#### Constraint
Ensure conditions are stated clearly and are logically comparable.
Avoid vague conditions (“nice”, “simple”, “large”).
