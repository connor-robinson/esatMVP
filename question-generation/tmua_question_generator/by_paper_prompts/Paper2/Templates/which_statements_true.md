### TEMPLATE: which_statements_true (AUTHORITATIVE)

You must implement the Designer plan using **statements I/II/III** (or I–IV if needed).

#### Required stem structure
- Provide a short setup (1–3 sentences), fully text-specified.
- Present **3 statements** labelled **I, II, III** (use IV only if required).
- Ask one of:
  - “Which statement(s) must be true?”
  - “Which statement(s) could be true?”
  - “Which statement(s) are necessarily true?”
  - “Which statement(s) are always true?”
- If the Designer plan implies a universal vs existential distinction, make that explicit in the ask.

#### Option form (high-quality)
Use a standard combination format, e.g.:
- A: I only
- B: II only
- C: III only
- D: I and II only
- E: I and III only
- F: II and III only
- (Optionally) G: I, II and III
- (Optionally) H: none

Choose 6–8 options depending on whether “all/none” are genuinely plausible outcomes.

#### Distractor requirements
- Each distractor must map to a specific reasoning pitfall:
  - confusing “must” with “can”
  - assuming converse/contrapositive
  - missing a boundary case
  - treating examples as proof
  - incorrect negation of a quantified statement
- Avoid options that differ only by triviality; make the combos meaningful.

#### Paper 2 constraints
- The truth status of each statement must be decidable under the given setup.
- No diagram dependency; any structure (grid, graph) must be fully described.
