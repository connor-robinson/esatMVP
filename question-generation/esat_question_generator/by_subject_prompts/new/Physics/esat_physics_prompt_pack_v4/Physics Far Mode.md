# Physics Far Mode V2

Goal: same schema invariant, but highly disguised or creatively remixed.

The question should appear to sit in a meaningfully different Physics area, representation, or task direction.

---

## Must Stay Same

- Same hidden reasoning move.
- Same target difficulty.
- ESAT Physics scope.
- Compact no-calculator solution.

---

## Use One or Two Remix Operators

1. Change the physical domain.
2. Change the representation.
3. Invert the task.
4. Encode the key condition indirectly.
5. Change from numerical result to statement selection.
6. Change from direct calculation to comparison.

---

## Collapse Moment

Every FAR idea must include a collapse moment:

> Once the candidate decodes the disguised setup, the solution reduces to one standard ESAT Physics move.

The Designer must state this collapse moment explicitly.

---

## FAR Must Not

- Use advanced derivations.
- Use obscure facts.
- Create a hidden-information puzzle.
- Require exact geometry.
- Require long arithmetic.
- Depend on a generated image for exact values.
- Stack multiple unrelated concepts.

---

## Calibration

FAR should feel new, but not weird.

Once the principle is spotted, the route should be fast and standard.
