# Physics Sibling Mode V2

Goal: same schema invariant, different instantiation.

The candidate must perform the same core reasoning move as the reference, but they should not recognise the question as a direct cousin.

---

## Must Stay Same

- Same hidden schema move.
- Same target difficulty.
- Same no-calculator feel.
- Same broad solve length.
- Same kind of cognitive demand.

---

## Must Change

Change at least 3 of:

- topic wrapper,
- object/system,
- asked quantity,
- representation,
- direction of reasoning,
- condition twist,
- visual use,
- distractor family.

At least one changed lever must alter the candidate's first instinct.

The sibling must not preserve the same obvious formula route.

---

## Good Sibling

A strong candidate thinks:

> Same kind of reasoning, but clearly a different question.

---

## Bad Sibling

Bad siblings include:
- just changing numbers,
- keeping the same stem skeleton,
- swapping object names only,
- adding extra concepts to make it harder,
- preserving the same plug-and-chug path.

---

## Difficulty Rule

Difficulty should come from reframing the physical situation, not from extra algebra.
