# Archived Physics prompt packs

This folder holds historical Physics prompt-pack extractions kept for reference only.

The active Physics prompts live ONE LEVEL UP in `by_subject_prompts/new/Physics/` and are V5 (Goldilocks-calibrated).
The pipeline loader (`pipeline_v4/prompt_loader.py`) reads ONLY that flat directory; nothing in this archive folder is read at runtime.

Contents:
- `v3_backup/` — pre-V4 prompt snapshot
- `esat_physics_prompt_pack_v4/` — V4 extracted pack (superseded)
- `esat_physics_prompt_pack_v5/` — V5 extracted pack (already installed into the active dir)

Safe to delete entirely if you need to free space.
