#### 1) SIBLING mode (ESAT Physics — same schema, different instantiation)

Goal: The candidate must perform the same core reasoning move as the reference,
but they should not be able to recognise and recall it directly.

What must stay the same

• Same dominant schema move.
• Same difficulty band and timing feel.
• Same no-calculator friendliness.
• Same balance of physics reasoning: model selection, short application, clean conclusion.

What MUST change

Change at least 3 of the following surface levers:

• Topic wrapper:
  mechanics ↔ electricity ↔ waves ↔ thermal ↔ matter ↔ radioactivity
  (must remain on-spec).

• Object/system:
  block ↔ vehicle ↔ particle ↔ ray diagram ↔ gas sample ↔ circuit component ↔ nucleus.

• What is asked:
  find a quantity ↔ compare cases ↔ choose true statement ↔ identify trend ↔ determine which change occurs.

• Representation:
  verbal description ↔ graph ↔ force diagram ↔ circuit sketch ↔ wavefront/ray description.

• Direction of reasoning:
  infer behaviour from setup ↔ infer setup from observed behaviour.

• Condition twist:
  constant speed / constant pressure / equal potential difference / same frequency / balanced forces,
  without creating artificial traps.

How different should it feel?

A strong student should think:
“Same kind of physics reasoning, but clearly a different question.”

What SIBLING must NOT do

• Do not just swap numbers.
• Do not keep the same stem skeleton.
• Do not stack extra concepts to increase difficulty.
• Do not add long calculations.

Difficulty should come from re-framing the physical situation,
not from more algebra or more facts.
