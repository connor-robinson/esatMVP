#### 2) FAR mode (ESAT Physics — highly disguised / creatively remixed)

Goal: Same schema invariant, but the question appears to sit in a meaningfully different Physics area or representation.

What must stay the same

• Same schema invariant: the hidden reasoning move is unchanged.
• Still ESAT Physics: short stem, school-physics, no long derivation, no advanced maths.

How to make it feel far while staying realistic

Use one (or at most two) remix operators:

1) Change the physical domain
   Example:
   - balanced forces ↔ equal resultant field effect
   - inverse-square style comparison ↔ intensity / pressure / electric relation if still on-spec

2) Change the representation
   - text ↔ graph
   - object description ↔ force diagram
   - circuit description ↔ symbolic circuit arrangement
   - wavefront picture ↔ verbal consequence

3) Invert the task
   Instead of asking for the outcome, ask:
   - which setup could produce the outcome?
   - which statement must be true?
   - which change would keep a quantity unchanged?

4) Encode the key condition indirectly
   - terminal velocity via zero resultant force
   - constant current via series reasoning
   - unchanged frequency via boundary behaviour
   - heating effect via energy transfer wording

What FAR must NOT do

• No advanced derivations.
• No long chains of equations.
• No hidden-information puzzles.
• No reliance on obscure factual recall.
• No graph-reading of precise values unless the graph is fully provided and central.

Calibration rule

FAR should feel new, but once the correct physical principle is recognised,
the route should collapse quickly to a standard school-physics move.

What to output in Designer JSON (FAR only)

surface_twist:
1–2 sentences describing what makes the surface feel different.

why_still_on_spec:
1–2 sentences naming the Physics domains used and explaining
why the structure reduces to standard ESAT Physics techniques.
