#### 1) SIBLING mode (ESAT Mathematics 1 — same schema, different instantiation)

Goal: The candidate must perform the same core reasoning move as the reference,
but they should not be able to recognise and recall it directly.

What must stay the same

• Same dominant schema move (the single structural idea being tested).
• Same difficulty band (similar mental load and step count).
• Same no-calculator friendliness (clean algebra, exact values, engineered simplifications).

What MUST change

Change at least 3 of the following surface levers:

• Object class:
  quadratic ↔ rational ↔ exponential/log ↔ trig ↔ sequence ↔ coordinate geometry
  (must remain standard A-level content).

• Constraint type:
  repeated root ↔ exactly one solution ↔ two intersections ↔ stationary point on axis
  ↔ sign condition ↔ behaviour on an interval.

• What is asked:
  find a parameter ↔ count solutions ↔ find a maximum/minimum
  ↔ determine range ↔ identify which statement must be true.

• Representation:
  purely algebraic ↔ derivative-based framing ↔ intersection description
  ↔ geometric interpretation (no diagram required).

• Direction of reasoning:
  instead of computing behaviour from a parameter,
  solve for the parameter given a required behaviour.

• Domain twist (fair only):
  restrict to positive reals / integers / a given interval / degrees vs radians,
  without creating artificial traps.

How “different” should it feel?

A strong student should think:
“Same kind of reasoning… but clearly a different question.”

If the reference uses a double-root condition, the sibling might present it as:
- stationary point on the axis,
- exactly one x-intercept,
- tangential intersection,
- or a symmetry-based argument,
but it must reduce to the same underlying A-level condition.

What SIBLING must NOT do

• Do not keep the same stem skeleton and just swap numbers.
• Do not reuse distinctive constants or structures from the reference.
• Do not stack additional schemas to increase difficulty.
• Do not introduce messy algebra or approximation.

Difficulty must come from disguise and re-framing,
not from adding extra concepts.
